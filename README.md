## 📱 Overview

**Expense Tracker** is an Android application that helps you manage your personal finances with ease — track income and expenses, set budgets, view statistics, and manage your money in Pakistani Rupees (Rs.). It also includes a built-in **AI Health Module** that predicts possible diseases based on symptoms.

---

## ✨ Features

### 💰 Expense Tracker
| Feature | Description |
|---|---|
| Add Income / Expense | Log transactions with title, amount, category, date, note |
| Budget Management | Set monthly budgets per category with progress tracking |
| Statistics | Visual charts showing spending by category and month |
| Pakistani Rupees | All amounts displayed in Rs. by default |
| Transaction History | Full list with edit and delete support |

## 🚀 Getting Started

### Prerequisites
- Android Studio Hedgehog (2023.1.1) or later
- Android SDK 34
- JDK 17

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/zebanazir37890/ExpenseTracker
   cd ExpenseTracker
   ```

2. **Open in Android Studio**
   - File → Open → select the `ExpenseTracker` folder

3. **Sync Gradle**
   - Android Studio will auto-sync. If not: File → Sync Project with Gradle Files

4. **Run the app**
   - Select a device or emulator (API 24+)
   - Click ▶ Run

> `local.properties` is auto-generated by Android Studio and is excluded from version control.

## 🗄️ Database Schema

```sql
CREATE TABLE expenses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT, amount REAL, category TEXT,
    date TEXT, note TEXT, type TEXT
);

CREATE TABLE budgets (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    category TEXT, budget_limit REAL, month TEXT
);

CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT, email TEXT UNIQUE, password TEXT,
    phone TEXT, age TEXT, gender TEXT, created_at TEXT
);

CREATE TABLE predictions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER, symptoms TEXT,
    disease1 TEXT, confidence1 REAL,
    disease2 TEXT, confidence2 REAL,
    disease3 TEXT, confidence3 REAL,
    severity TEXT, pred_date TEXT, doctor_alert INTEGER
);
```
